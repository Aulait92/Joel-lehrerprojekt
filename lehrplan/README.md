# Lehrplan-Quellen

Lege hier die für dich relevanten Teile des **Rahmenlehrplans Berlin-Brandenburg** ab
(PDF oder als Text kopiert), z. B.:

- `teil-b-basiscurriculum-sprachbildung.pdf`
- `teil-c-mathematik.pdf`
- `teil-c-deutsch.pdf`

Download: https://bildungsserver.berlin-brandenburg.de/rlp-online/

Der Agent `lehrplan-analyst` durchsucht diesen Ordner **zuerst**. Mit lokalen Dateien sind die
Standard-Zitate verlässlicher, als wenn er aus dem Gedächtnis oder per Websuche arbeitet.
