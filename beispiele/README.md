# Beispiel mit erfundenen Daten

`klasse-7x/` enthält **vollständig erfundene** Ergebnisse (27 fiktive Kürzel, zufällig simuliert) für die Einheit
„Brüche und Dezimalzahlen“: Eingangstest, drei Exit-Tickets, Klassenarbeit – plus die automatisch erzeugten
Berichte in `klasse-7x/auswertungen/`. Damit kannst du dir ansehen, was die Auswertung liefert, bevor du echte
Daten erfasst. Echte Klassendaten gehören **immer** nach `klassen/` (wird nicht hochgeladen).

Neu erzeugen:
```
python3 tools/lernauswertung.py verlauf --index beispiele/klasse-7x/tests.csv
```
