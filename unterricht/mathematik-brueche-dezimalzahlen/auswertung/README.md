## So trägst du ein
- Vorlage nach `klassen/<klasse>/<JJJJ-MM-TT>_<test>.csv` kopieren (**nicht hier ausfüllen** – dieser Ordner wird geteilt).
- Pro Kürzel und Aufgabe die Punkte: `1`, `0,5`, `0` …
- Fehlerbild dazuschreiben, wenn erkennbar: `0:LG`, `0,5:KV`, mehrere mit `+`: `0:LG+KG`. Kürzel siehe `02-diagnose.md`, Abschn. 4/5.
- `-` = Aufgabe vorgelegt, aber nichts geschrieben. **Leer** = nicht vorgelegt bzw. andere Wahlvariante (Exit-Tickets, Wahlteil der Klassenarbeit).
- **Exit-Tickets:** nur die gewählte Aufgabe ausfüllen, 2 = sicher, 1 = fast, 0 = noch nicht (entspricht den drei Stapeln).
- **Klassenarbeit:** Teil A je Aufgabe, im Wahlteil nur die gewählte Variante je Block (z. B. `B1-2`).

Die Gruppenregel im Skript („sicher“ ab 66 % einer Stufe) entspricht nahezu der Regel in `02-diagnose.md`, Abschn. 5. Die Sonderfälle dort (z. B. „E sicher, aber D-Lücke“) prüft der `lernfortschritt-analyst` zusätzlich.
