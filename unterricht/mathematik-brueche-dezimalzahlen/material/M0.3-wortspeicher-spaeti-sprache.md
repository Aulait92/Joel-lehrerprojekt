## Späti-Sprache 1: Mein Wortspeicher

**So nutzt du die Karte:** Wenn dir ein Wort fehlt: Schau hier nach.
In der letzten Spalte kannst du das Wort in **deiner Sprache** aufschreiben.

### Wörter für Brüche

| Wort (mit Artikel) | Mehrzahl | Mini-Beispiel | In meiner Sprache |
|---|---|---|---|
| **der Bruch** | die Brüche | ¾ ist ein Bruch. | |
| **der Zähler** | die Zähler | ¾ → **3** ist der Zähler. Er **zählt** die Teile. | |
| **der Nenner** | die Nenner | ¾ → **4** ist der Nenner. Er **nennt** die Teile-Größe: Viertel. | |
| **der Bruchstrich** | die Bruchstriche | Der Strich zwischen 3 und 4. Er heißt „geteilt“: ¾ = 3 : 4 | |
| **der Stammbruch** | die Stammbrüche | Ein Bruch mit Zähler 1: ½, ⅓, ¼ | |
| **gleichnamig** | – | ⅕ und ⅖ sind gleichnamig (gleicher Nenner). | |
| **der Hauptnenner** | die Hauptnenner | ½ und ⅓ → Hauptnenner 6 | |
| **erweitern** | er/sie erweitert | ½ = 2/4 (oben und unten · 2) | |
| **kürzen** | er/sie kürzt | 6/8 = ¾ (oben und unten : 2) | |
| **der Kehrwert** | die Kehrwerte | Kehrwert von ¾ ist 4/3 (umdrehen) | |
| **der Anteil** | die Anteile | 9 von 12 Flaschen → Anteil 9/12 | |
| **das Ganze** | – | eine volle Kiste, eine ganze Tafel = 1 | |
| **die Hälfte** | die Hälften | ½ – in 2 gleiche Teile teilen | |
| **das Viertel** / **das Drittel** | die Viertel / die Drittel | ¼ / ⅓ | |
| **gleich groß** | – | Alle Teile müssen **gleich groß** sein. | |

| **das Tausendstel** | die Tausendstel | 0,00**1** = 1/1000 (bei kg: 1 Gramm) | |

### Arbeitsanweisungen (Operatoren) – was soll ich tun?

| Operator | Das tust du |
|---|---|
| **vergleichen** | Du sagst, was größer, kleiner oder gleich ist (>, <, =). |
| **ordnen** | Du bringst Zahlen in eine Reihenfolge, meist von klein nach groß. |
| **umwandeln** | Du schreibst dieselbe Zahl anders: ½ → 0,5 → 50 %. |
| **berechnen** | Du rechnest und schreibst die Rechnung auf. |
| **überschlagen** | Du rechnest mit gerundeten Zahlen, um das Ergebnis ungefähr zu wissen. |
| **begründen** | Du schreibst, **warum** etwas stimmt. Satzanfang: „…, weil …“ |
| **erklären** | Du beschreibst so, dass es ein:e andere:r versteht (Schritt für Schritt). |
| **prüfen** | Du kontrollierst, ob etwas richtig ist, und sagst, was falsch ist. |
| **ausfüllen** / **ergänzen** | Du schreibst in die leeren Felder oder Lücken. |
| **einkreisen** / **ankreuzen** | Du machst einen Kreis ◯ um die Antwort / ein Kreuz ☒ in das Kästchen. |
| **finden** | Du probierst aus und schreibst auf, was passt. |
| **zeichnen** / **ausmalen** | Du malst ein Bild, einen Streifen oder Punkte am Zahlenstrahl. |
| **beschreiben** | Du schreibst auf, **wie** du vorgegangen bist: erst …, dann … |
| **entscheiden** | Du wählst eine Möglichkeit und sagst, warum. |
| **erfinden** | Du denkst dir selbst eine Aufgabe oder ein Beispiel aus. |
| **korrigieren** | Du schreibst das Falsche richtig hin. |
| **untersuchen** | Du probierst mehrere Beispiele aus und suchst eine Regel. |
| **zeigen** | Du beweist mit Rechnung oder Bild, dass etwas stimmt. |

## Späti-Sprache 2: Signalwörter, Sprechen, Satzmuster

### Signalwörter – welche Rechnung steckt im Text?

| Wenn im Text steht … | dann rechnest du meist … | Beispiel |
|---|---|---|
| **von** (die Hälfte **von**, ¾ **von**) | **mal** (·) | ¾ **von** 12 € = ¾ · 12 € = 9 € |
| **je**, **pro**, **à**, **für ein** | Preis für **1** Stück / kg / l | 4,90 € **je** kg = 4,90 €/kg |
| **passt in**, **wie oft**, **wie viele … aus** | **geteilt** (:) | Wie oft **passt** ½ l **in** 3 l? 3 : ½ = 6 |
| **zusammen**, **insgesamt**, **dazu** | **plus** (+) | ½ Kiste und ¼ Kiste **zusammen** |
| **Rest**, **übrig**, **fehlt**, **zurück** | **minus** (−) | Wie viel **fehlt** bis zur vollen Kiste? |
| **gratis**, **umsonst** | kostet **0 €** | „⅓ gratis“ |
| **Rabatt**, **reduziert**, **billiger um** | vom Preis **abziehen** | 10 € mit 20 % Rabatt → 10 € − 2 € = 8 € |

### So spricht man Zahlen

| Zahl | So sagt man es | Achtung |
|---|---|---|
| 0,34 | „null Komma **drei vier**“ | **nicht** „null Komma vierunddreißig“ |
| 2,05 | „zwei Komma null fünf“ | |
| 3,05 € | „drei Euro fünf“ | 5 Cent, nicht 50 Cent! |
| 0,3̅ | „null Komma Periode drei“ | |
| 37,5 % | „siebenunddreißig Komma fünf Prozent“ | |
| ½ · ⅓ · ¼ | „ein **halb**“ · „ein **Drittel**“ · „ein **Viertel**“ | ½ heißt auch „die Hälfte“ |
| ⅗ · ⅞ · 5/12 | „drei Fünf**tel**“ · „sieben Ach**tel**“ · „fünf Zwölf**tel**“ | bis 19: **-tel** |
| 1/20 · 3/100 | „ein Zwanzig**stel**“ · „drei Hundert**stel**“ | ab 20: **-stel** |
| ⅓ < ½ | „ein Drittel ist **kleiner als** ein halb“ | < kleiner als · > größer als |

### Satzmuster

**Vergleichen und ordnen**
- *„… ist größer als …, denn …“*
- *„… muss weiter links halten, weil …“*
- *„… und … sind gleich groß, weil …“*

**Umwandeln, kürzen, erweitern**
- *„Ich erweitere …, weil …“*
- *„Ich kürze … durch …, weil Zähler und Nenner beide durch … teilbar sind.“*
- *„… ist dasselbe wie …, denn …“*

**Fehler finden**
- *„… stimmt nicht, weil …“*
- *„Der Fehler ist: …. Richtig ist …“*
- *„Mein Überschlag ist …. Das Ergebnis … passt (nicht) dazu.“*

**Entscheiden und begründen**
- *„Angebot … ist günstiger, weil …“*
- *„Ich habe zuerst …, dann … gerechnet.“*
- *„Der Anteil ist …, denn … von … sind …“*

**Kurze Sätze für den Start** (wenn Deutsch noch neu ist)
- *„Das ist … .“* (Das ist ¾.)
- *„… ist größer / kleiner.“*
- *„Ich rechne: … .“*
- *„Ich weiß nicht: … . Kannst du mir helfen?“*
- *„Ich verstehe das Wort … nicht.“*

| Std. | Schwerpunkt auf der Karte | Impuls |

| 4 | Komma, Zehntel/Hundertstel, Überschlag, Wechselgeld | „Mein Überschlag ist …“ |

**Hinweise**
- Spalte „In meiner Sprache“ für DaZ-Lernende; auch Herkunftssprachen-Expert:innen der Klasse können als Übersetzer:innen eingesetzt werden. Für LRS: Karte auf A3 vergrößern.
- **„Komma“ – Plural:** „die Kommas“ (auch „die Kommata“ ist korrekt; im Unterricht reicht „Kommas“).
- Signalwörter sind **Faustregeln** („meist“): Im Kassensturz bewusst ein Gegenbeispiel thematisieren (z. B. „3 € **von** 10 € abziehen“ → minus), damit kein mechanisches Übersetzen entsteht.
- Lösungen/Selbstkontrolle: Die Karte ist ein Nachschlagewerk; alle Beispiele sind gerechnet und korrekt (¾ · 12 € = 9 €; 3 : ½ = 6; 5 € − 3,20 € = 1,80 €; 10 € − 20 % = 8 €; Hauptnenner von ½ und ⅓ = 6).
- Keine Niveausymbole auf der Karte: Der Wortspeicher gilt für alle; 🌱-Lernende bekommen auf den Auftragskarten zusätzlich passende Satzanfänge.
- **Ergänzungen Inklusion (s. `05-inklusion.md`):** Operatorenliste um die Verben erweitert, die in M1.1–M8.1 tatsächlich vorkommen (ausfüllen, einkreisen, finden, zeichnen, beschreiben, entscheiden, erfinden, korrigieren, untersuchen, zeigen). Neu sind außerdem Hälfte/Viertel/Drittel, kg/g/l, billiger/teurer und „Kurze Sätze für den Start“ für Lernende aus der Willkommensklasse.
- **Bildunterstützung:** Für Lernende mit wenig Deutsch neben die Wörter Bruch, Zähler, Nenner, Komma, Prozent, Rabatt, Kassenbon und Waage je ein kleines Piktogramm kleben [Bild: z. B. Pizza mit 3 von 4 Stücken markiert bei „der Bruch“]. Auf der Karte ist dafür kein Platz vorgesehen, deshalb eine A3-Version für die Tafel/Wand erstellen.
- **Mehrsprachigkeit:** Die Spalte „In meiner Sprache“ in Std. 1 gemeinsam füllen (Partner:innen mit gleicher Herkunftssprache, Bildwörterbuch, Schulgerät mit Übersetzungsapp). Lohnender Sprachvergleich: Im Türkischen (und z. B. im Chinesischen) wird bei Brüchen zuerst der Nenner genannt (tr. „dörtte üç“, wörtlich etwa „in vier drei“ für ¾). Das ist eine mögliche Quelle für vertauschte Zähler/Nenner (sprachlich bedingt, kein Mathe-Fehler). Bitte mit den Lernenden selbst prüfen, nicht unterstellen.
- **Komma vs. Punkt:** In vielen Herkunftsländern (und im Englischen / auf Taschenrechnern) ist der Dezimal**punkt** üblich, und das Komma trennt Tausender. Einmal ausdrücklich thematisieren (Std. 2).
