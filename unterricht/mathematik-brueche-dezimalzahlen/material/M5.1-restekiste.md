## Schicht 5: Die Restekiste

Im Lager vom Späti „Zum Bruchstück“ stehen viele **angebrochene Kisten** mit Nüssen.
Frau Yıldız schreibt: *„Bitte legt die Reste zusammen. Ich will nur volle Kisten im Regal!“*

**Eine volle Kiste = 1 Kiste = 1 kg Nüsse.**
Darum gilt: ¼ Kiste = 0,25 kg, ½ Kiste = 0,5 kg.

[Bild: drei gleich große Kisten – eine voll („1 kg“), eine halb voll („½ Kiste = 0,5 kg“), eine zu einem Viertel voll („¼ Kiste = 0,25 kg“)]

**Wortspeicher**

| Wort | Beispiel |

## Lösungen M5.1

### Offene Kernaufgabe – mögliche Kombinationen (Auswahl)

| Karten | Rechnung |
|---|---|
| A + J | ½ + 0,5 = 1 |
| B + K / I + K | ¼ + 0,75 = 1 (0,25 + 0,75 = 1) |
| D + E | ⅜ + ⅝ = 8/8 = 1 |
| F + H | ⅓ + ⅔ = 3/3 = 1 |
| G + L | ⅙ + ⅚ = 6/6 = 1 |
| A + B + I / J + B + I | ½ + ¼ + 0,25 = 1 |
| A + D + C / J + D + C | ½ + ⅜ + ⅛ = 4/8 + 3/8 + 1/8 = 1 |
| E + B + C / E + I + C | ⅝ + ¼ + ⅛ = 5/8 + 2/8 + 1/8 = 1 |
| B + C + D + I | ¼ + ⅛ + ⅜ + 0,25 = 2/8 + 1/8 + 3/8 + 2/8 = 1 |
| A + F + G / J + F + G | ½ + ⅓ + ⅙ = 3/6 + 2/6 + 1/6 = 1 |
| F + G + B + I | ⅓ + ⅙ + ¼ + 0,25 = ½ + ½ = 1 |
| F + G + D + C | ⅓ + ⅙ + ⅜ + ⅛ = ½ + ½ = 1 |

Typischer Fehler: ½ + ⅓ = 2/5 → **ZN** (Hilfekarte H-ZN). Gegenprobe: Das Ergebnis muss **größer** sein als jeder Summand.

(3) Neuntel passen nicht zu Dritteln und Sechsteln einer Kiste. b) Kemal hat Zähler + Zähler (1 + 1) und Nenner + Nenner (3 + 6) gerechnet (**ZN**). Die Nenner geben aber die **Größe** der Teile an – die darf man nicht addieren. |
| ☆ | Beispiel: ½ und ¼ → (1+1)/(2+4) = 2/6 = ⅓; ⅓ liegt zwischen ¼ und ½. Begründung: Die Summe zweier positiver Brüche ist **größer als jeder Summand**. Kemals Zahl ist aber **höchstens so groß wie der größere** Bruch. Also kann sie nie die Summe sein. |

**⭐ Profi-Challenge – Herleitung:** In Achteln: A = 4, B = 2, C = 1, D = 3, E = 5, I = 2, J = 4, K = 6. Ziel: 8.
Systematisch nach der größten Karte sortieren:
- mit K (6): K+B, K+I → 2
- ohne K, mit E (5): E+D, E+B+C, E+I+C → 3
- ohne K, E, mit A (4): A+J, A+B+I, A+D+C → 3
- ohne K, E, A, mit J (4): J+B+I, J+D+C → 2
- nur B, C, D, I: B+C+D+I (2+1+3+2) → 1

**11 Kartenkombinationen.** Zählt man gleiche Werte (¼ = 0,25 kg, ½ = 0,5 kg) nur einmal, sind es **7 verschiedene Wertekombinationen**: 6+2, 5+3, 5+2+1, 4+4, 4+3+1, 4+2+2, 3+2+2+1. Die Reihenfolge zählt nicht (Addition ist kommutativ). Beide Antworten sind richtig, wenn die Regel klar formuliert ist.
