## Teil B – Hilfekarten (Kopiervorlage zum Ausschneiden)

> ✂ ---------- H1 Denkanstoß ----------

### H1 – Wo kann ich einen rechten Winkel erzeugen?

- sin, cos und tan gelten **nur** im rechtwinkligen Dreieck. Dein Dreieck hat keinen rechten Winkel – also **erzeugst** du einen.
- Die **Höhe** ist ein Lot: Sie geht von einer Ecke aus und trifft die gegenüberliegende Seite **im rechten Winkel**.
- **Frage dich:** Von welcher Ecke aus muss ich das Lot fällen, damit die **bekannte Seite** die **Hypotenuse** eines Teildreiecks wird?
- Ist ein Winkel **stumpf**? Dann verlängere die Seite und fälle das Lot auf die Verlängerung.

> ✂ ---------- H2 Strategie: Zerlegen in 4 Schritten ----------

### H2 – Zerlegen in 4 Schritten

| Schritt | Was tun? | Beispiel (Dreieck mit b, α, β bekannt) |
|---|---|---|
| **1 Skizze + Höhe** | Höhe so einzeichnen, dass die bekannte Seite Hypotenuse wird. Rechte Winkel markieren, Teildreiecke ① und ② nummerieren. | Höhe h von C auf c. In ① ist b die Hypotenuse. |
| **2 Höhe berechnen** | Im Teildreieck ① mit sin (oder cos). | h = b · sin(α) |
| **3 Zweites Teildreieck** | Fehlenden Winkel über die Winkelsumme bestimmen (falls nötig). h ist wieder Kathete: aufschreiben, dann umstellen. | h = a · sin(β) ⇒ a = h : sin(β) |
| **4 Prüfen** | Größte Seite gegenüber dem größten Winkel? Einheit? Sinnvoll gerundet? Antwortsatz. | a < b, weil α < β ✓ |

**Rechne mit dem ungerundeten h weiter (Taste Ans).**

> ✂ ---------- H3 Parallelbeispiel (andere Zahlen) ----------

### H3 – Ein vollständig gerechnetes Beispiel

Gegeben: b = 7,5 cm, α = 44°, β = 58°. Gesucht: Seite a.

```dreieck
winkel_A: 44
winkel_B: 58
seiten: AC="b = 7,5 cm" BC="a = ?" AB="c"
winkel: A="α = 44°" B="β = 58°"
breite: 240
```

| Schritt | Rechnung |
|---|---|
| 1 | Höhe h von C auf c, Fußpunkt D. Teildreieck ① = ADC (Hypotenuse b), ② = DBC (Hypotenuse a). |
| 2 | sin(44°) = h : 7,5 ⇒ h = 7,5 · sin(44°) = 7,5 · 0,6947 ≈ 5,21 cm (im TR lassen) |
| 3 | sin(58°) = h : a ⇒ a · sin(58°) = h ⇒ a = h : sin(58°) = 5,210 : 0,8480 ≈ **6,1 cm** |
| 4 | γ = 180° − 44° − 58° = 78° ist der größte Winkel. a = 6,1 cm < b = 7,5 cm, weil 44° < 58° ✓ |

> ✂ ---------- H3b Parallelbeispiel Zwei Standpunkte (◼◼) ----------

### H3b – Zwei Standpunkte, durchgerechnet

Gegeben: d = 12,0 m, α₁ = 42° (näher), α₂ = 28° (weiter weg), Augenhöhe 1,60 m.

| Schritt | Rechnung |
|---|---|
| 1 | Winkel bei der Dachkante D = 42° − 28° = 14°. Lot von S₁ auf die Sichtlinie S₂D (Fußpunkt L). |
| 2 | Teildreieck S₂LS₁ (Hypotenuse d): S₁L = 12,0 · sin(28°) ≈ 5,634 m |
| 3 | Teildreieck S₁LD (Hypotenuse S₁D): S₁D = 5,634 : sin(14°) ≈ 23,29 m |
| 4 | x = 23,29 · sin(42°) ≈ **15,58 m** · Dachhöhe ≈ 15,58 + 1,60 ≈ **17,2 m** |
| Probe | e₁ = 23,29 · cos(42°) ≈ 17,31 m; 17,31 · tan(42°) ≈ 15,58 m ✓ |
