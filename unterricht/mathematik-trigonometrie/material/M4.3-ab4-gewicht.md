### Zerlegen in rechtwinklige Teildreiecke

**Merke:** Zeichne die Höhe so ein, dass die **bekannte Seite** die **Hypotenuse** eines rechtwinkligen Teildreiecks wird. Rechne mit dem ungerundeten Zwischenergebnis weiter (**Ans**). Längen am Ende auf eine Nachkommastelle runden.

**Aufgabe 1) ★ Zeichne** die Höhe h_c von C auf die Seite c ein. **Berechne** h_c, a und c.

```dreieck
winkel_A: 42
winkel_B: 71
seiten: AC="b = 9,4 cm" BC="a" AB="c"
winkel: A="α = 42°" B="β = 71°"
breite: 280
```

**Aufgabe 2) ★** Hier ist **c** bekannt. **Zeichne** eine Höhe so ein, dass c die Hypotenuse eines Teildreiecks wird. **Berechne** die Seite a.
**Begründe** zuerst in einem Satz: Warum hilft die Höhe von C auf c hier **nicht**?

```dreieck
winkel_A: 54
winkel_B: 60
seiten: AB="c = 11,0 cm" AC="b" BC="a = ?"
winkel: A="α = 54°" B="β = 60°"
breite: 280
```

**Aufgabe 3) ★ Grundstück im Kiez** (Werte angenommen). Ein dreieckiges Grundstück grenzt mit 32,0 m an die Straße. Die Grenzen zum Nachbarn bilden mit der Straße die Winkel 74° (bei A) und 48° (bei B).
**Zeichne** in die Skizze eine passende Höhe ein. **Berechne** die Länge des Zauns von B nach C.
*Zusatz:* **Berechne** die Fläche des Grundstücks (auf ganze m²).

```dreieck
winkel_A: 74
winkel_B: 48
seiten: AB="Straße 32,0 m" BC="Zaun = ?"
winkel: A="74°" B="48°"
breite: 260
```

```dreieck
winkel_A: 60
```
