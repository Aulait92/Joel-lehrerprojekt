## Teil C – Lösung: ausgefüllte Lehrerfassung (nicht austeilen)

**Paare:** ● a und α · ■ b und β · ▲ c und γ.

**Merke: Der Sinussatz**

  a : sin(α) = b : sin(β) = c : sin(γ)   (auch als Brüche: a/sin α = b/sin β = c/sin γ)

In Worten: Der Quotient aus einer **Seite** und dem **Sinus** des gegenüberliegenden **Winkels** ist für alle drei Paare **gleich**.

**Herleitung**

| Schritt | Lösung |
|---|---|
| 1 | … in zwei **rechtwinklige** Teildreiecke AFC und BFC. |
| 2 | sin(α) = **h_c / b**, umgestellt h_c = **b** · sin(α) |
| 3 | sin(β) = **h_c / a**, umgestellt h_c = **a** · sin(β) |
| 4 | **b** · sin(α) = **a** · sin(β) |
| 5 | **a : sin(α) = b : sin(β)** |

**Für Profis:** h_a teilt das Dreieck in die Teildreiecke mit den Hypotenusen c (Winkel β) und b (Winkel γ): h_a = c · sin(β) = b · sin(γ) → b : sin(β) = c : sin(γ). Zusammen mit Schritt 5 gilt der Satz für alle drei Paare. *Hinweis:* Ist β stumpf, liegt F außerhalb von AB. Die Rechnung gilt trotzdem, weil sin(180° − β) = sin(β) (Ausblick, nur mündlich).

**Wann hilft der Sinussatz?** WSW/SWW: **ja** · SSW: ja, evtl. zwei Lösungen · SWS: **nein** · SSS: **nein**.

**Beispiel:** vollständiges Paar b = 6,0 cm und β = 40° · Paar mit gesuchter Größe c und γ = 75°
Ansatz c : sin(75°) = 6,0 : sin(40°) → c = 6,0 · sin(75°) : sin(40°)
TR: 6 × sin 75 ÷ sin 40 = 5,79556 : 0,64279 ≈ 9,016 → **c ≈ 9,0 cm**
Prüfung: α = 180° − 40° − 75° = 65°. Größter Winkel γ = 75° liegt der längsten Seite c = 9,0 cm gegenüber ✓ (a = 6,0 · sin 65° : sin 40° ≈ 8,5 cm, b = 6,0 cm).
