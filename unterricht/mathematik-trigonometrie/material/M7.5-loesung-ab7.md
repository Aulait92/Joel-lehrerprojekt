# M7.5 – Lösungsblatt AB7 Kosinussatz 🪶 / ◼ / ◼◼

## Teil A – Für die Lehrkraft (nicht austeilen)

- **Einsatz:** Std. 7, Lösungsstation am Fenster (jedes Niveau auf einer eigenen Seite, einzeln auslegbar) und Grundlage für die Code-Kontrolle.
- **Rundung:** Zwischenergebnisse im Taschenrechner lassen (Ans-Taste), erst am Ende runden. Werte unten mit cos auf 4 Nachkommastellen, Winkel auf 0,1°. Alle Ergebnisse wurden zweimal unabhängig gerechnet.
- **Codes:** 🪶 **KRAN** · ◼ **RADIO** · ◼◼ **MASTEN**. Falsche Buchstaben zeigen das Fehlerbild an (Tabellen am Ende jedes Abschnitts).
- **Fehlerbilder (01, Abschn. 7):** KVZ Vorzeichen · KZU falscher Winkel · KRF Rechenreihenfolge/Wurzel · RAD · RUND · PLAU · FALL.

**Taschenrechner-Eingabe (für alle Niveaus):**
Seite: `a x² + b x² − 2 × a × b × cos(γ) =` → `√(Ans) =`
Winkel (◼◼): `SHIFT cos ( (a x² + b x² − c x²) ÷ (2 × a × b) ) =` – Klammer um den ganzen Zähler und um den ganzen Nenner.

## Teil C – Lösung 🪶 Feder (Code KRAN)

**Aufgabe 1)** c² = a² + b² − 2 · a · b · cos(γ)

| Schritt | Rechnung | Ergebnis |
|---|---|---|
| 1 | 4,0² + 6,0² = 16 + 36 | 52 |
| 2 | 2 · 4,0 · 6,0 · cos(60°) = 48 · 0,5 | 24 |
| 3 | 52 − 24 | 28 (= c²) |
| 4 | c = √28 | **c ≈ 5,3 cm** → **K** |

**Aufgabe 2)** Gesucht a, gegenüber liegt **α = 45°**. a² = b² + c² − 2 · b · c · cos(α)

| Schritt | Rechnung | Ergebnis |
|---|---|---|
| 1 | 5,0² + 8,0² = 25 + 64 | 89 |
| 2 | 2 · 5,0 · 8,0 · cos(45°) = 80 · 0,7071 | ≈ 56,57 |
| 3 | 89 − 56,57 | ≈ 32,43 (= a²) |
| 4 | a = √32,43 | **a ≈ 5,7 cm** → **R** |

**Aufgabe 3)** KS² = 120² + 80² − 2 · 120 · 80 · cos(110°)

| Schritt | Rechnung | Ergebnis |
|---|---|---|
| 1 | 120² + 80² = 14 400 + 6 400 | 20 800 |
| 2 | 2 · 120 · 80 · cos(110°) = 19 200 · (−0,3420) | ≈ −6 566,8 |
| 3 | 20 800 − (−6 566,8) = 20 800 + 6 566,8 | ≈ 27 366,8 |
| 4 | KS = √27 366,8 | ≈ 165,4 → **etwa 165 m** → **A** |

Antwort: *Der Kiosk ist vom Spielplatz etwa 165 m entfernt.* Plausibel: Bei 90° wären es √20 800 ≈ 144 m. Der Winkel ist stumpf, also muss KS länger sein. Kürzer als 120 m + 80 m = 200 m ist es auch.

**Aufgabe 4)** Schritt 1: 6,0² + 8,0² = 100. Schritt 2: 2 · 6,0 · 8,0 · cos(90°) = 96 · 0 = 0. Schritt 3: 100 − 0 = 100. Schritt 4: c = √100 = **10 cm** → **N**.
*Bei γ = 90° ist cos(γ) = 0. Deshalb fällt die Korrektur weg, und es bleibt der Satz des Pythagoras: c² = a² + b².*

**Aufgabe 5)** Ben hat zuerst 58 − 42 gerechnet und dann mit 0,5 multipliziert (**KRF**). Es gilt aber Punkt- vor Strichrechnung: Erst wird 2 · 3,0 · 7,0 · cos(60°) = 21 ausgerechnet, dann abgezogen.
Richtig: c² = 9 + 49 − 21 = 37 → c = √37 ≈ **6,1 cm**.

## Teil C – Lösung ◼ Gewicht (Code RADIO)

= 324 + 42,25 − 234 · 0,2588
≈ 366,25 − 60,56 = 305,69
s = √305,69 ≈ **17,5 m** → **R**.
Plausibel: Das Seil ist etwas kürzer als der Ausleger, weil die Turmspitze nur 6,5 m über dem Gelenk liegt und der Winkel spitz ist.

**Aufgabe 2) Grundstück.**

## Teil C – Lösung ◼◼ Doppelgewicht (Code MASTEN)

**Aufgabe 1) Herleitung.**
Teildreieck ADC (rechter Winkel bei D): cos(α) = x / b ⇒ **x = b · cos(α)**. Pythagoras: **h² = b² − x²**.
Teildreieck DBC (rechter Winkel bei D): **a² = h² + (c − x)²**.
Einsetzen: a² = b² − x² + c² − 2cx + x² = b² + c² − 2c · x.
Mit x = b · cos(α): **a² = b² + c² − 2 · b · c · cos(α)** ∎
*Zusatz (α stumpf):* D liegt auf der Verlängerung von AB über A hinaus. Dann ist AD = x′ = b · cos(180° − α) = −b · cos(α) und DB = c + x′.
a² = h² + (c + x′)² = b² − x′² + c² + 2cx′ + x′² = b² + c² + 2c · x′ = b² + c² − 2bc · cos(α). Die Formel gilt also auch hier. Der negative Kosinus erledigt den Vorzeichenwechsel „automatisch“.

**Aufgabe 2) Altbau-Giebel.** Bezeichnung: c = AB = 12,8 m, a = BC = 9,4 m, b = AC = 7,2 m.
a) c² = a² + b² − 2ab · cos(γ) ⇒ 2ab · cos(γ) = a² + b² − c² ⇒ **cos(γ) = (a² + b² − c²) / (2ab)**
b) Am besten zuerst den größten Winkel γ (gegenüber der längsten Seite):
cos(γ) = (88,36 + 51,84 − 163,84) / (2 · 9,4 · 7,2) = −23,64 / 135,36 ≈ −0,1746 → **γ ≈ 100,1°** → **S**
cos(α) = (b² + c² − a²) / (2bc) = (51,84 + 163,84 − 88,36) / 184,32 = 127,32 / 184,32 ≈ 0,6908 → **α ≈ 46,3°** → **M**
cos(β) = (a² + c² − b²) / (2ac) = (88,36 + 163,84 − 51,84) / 240,64 = 200,36 / 240,64 ≈ 0,8326 → **β ≈ 33,6°** → **A**
c) 46,3° + 33,6° + 100,1° = 180,0° ✓. sin⁻¹ liefert nur Winkel bis 90°. Mit dem Sinussatz erhielte man sin(γ) = 12,8 · sin(46,3°) / 9,4 ≈ 0,9846 und damit γ ≈ 79,9° (**K** = Fehler). Richtig wäre 180° − 79,9° = 100,1°. Der Kosinus ist für stumpfe Winkel negativ und unterscheidet deshalb eindeutig. Ist der größte Winkel berechnet, sind die beiden anderen sicher spitz.

**Aufgabe 3) Pythagoras als Sonderfall.**
a) cos(90°) = 0 ⇒ 2ab · cos(90°) = 0 ⇒ c² = a² + b². Der Satz des Pythagoras ist der Kosinussatz für γ = 90°.
b) cos(γ) = (6,5² + 7,2² − 9,7²) / (2 · 6,5 · 7,2) = (42,25 + 51,84 − 94,09) / 93,6 = 0 / 93,6 = 0 ⇒ **γ = 90°** → **T**. Das Dreieck aus AB1 ist rechtwinklig. Der Kosinussatz liefert die Umkehrung des Pythagoras.
c) cos(γ) > 0 für γ < 90°: Es wird etwas abgezogen, also c² < a² + b². cos(γ) < 0 für γ > 90°: „Minus mal Minus“, also c² > a² + b². Bei γ = 90° gilt Gleichheit.

**Aufgabe 4) Stumpfer Winkel** (a = 5,0 cm, b = 8,0 cm, a² + b² = 89, 2ab = 80)

| γ | 30° | 90° | 150° | fast 180° | fast 0° |
|---|---|---|---|---|---|
| cos(γ) | 0,8660 | 0 | −0,8660 | fast −1 | fast 1 |
| c² | 89 − 69,28 = 19,72 | 89 | 89 + 69,28 = 158,28 | fast 169 | fast 9 |
| c in cm | **≈ 4,4** → **E** | ≈ 9,4 | **≈ 12,6** → **N** | fast 13 | fast 3 |

b) γ → 180°: c → a + b = 13 cm. Das Dreieck klappt zu einer Strecke auf. γ → 0°: c → b − a = 3 cm. Die Seiten liegen aufeinander. Je stumpfer der Winkel, desto länger wird c.

**Aufgabe 5) Profi-Challenge.** cos(γ) = (4² + 5² − 10²) / (2 · 4 · 5) = −59 / 40 = −1,475. Der Kosinus eines Winkels liegt aber immer zwischen −1 und 1, deshalb meldet cos⁻¹ einen Fehler. Geometrisch gilt 4 cm + 5 cm = 9 cm < 10 cm: Die beiden kurzen Seiten reichen nicht bis zu den Enden der langen Seite (Dreiecksungleichung verletzt).

**Code MASTEN** (M-A-S-T-E-N). Falsche Buchstaben:

| Buchstabe | Wert | Fehler |
|---|---|---|
| K | 79,9 | A2: γ mit sin⁻¹ bestimmt, stumpfer Winkel übersehen (**FALL/PLAU**) |
| R | 9,4 | A4: Wert für 90° statt 30° bzw. 150° |
| O / U | 19,7 / 158,3 | A4: Wurzel vergessen (**KRF**) |

Weitere typische Fehler: falscher Winkel zur Seite (**KZU**, z. B. α mit (a² + b² − c²) / (2ab) berechnet) · fehlende Klammern bei cos⁻¹ (**KRF**) · „negativer Kosinus ist ein Fehler“ (**PLAU**).
