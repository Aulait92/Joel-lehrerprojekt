**3. Winkel berechnen – Umkehrfunktion**
Casio: **SHIFT** + **sin** → sin⁻¹(   · TI: **2nd** + **sin** → sin⁻¹(
Beispiel: sin(α) = 3 : 5 → **SHIFT sin ( 3 ÷ 5 ) =** → **36,869…** → α ≈ 36,9°
**Klammer** um den Bruch nicht vergessen!

**Achtung:** sin⁻¹ ist **nicht** 1 : sin. Das „hoch minus 1“ heißt hier „rückwärts rechnen“.

> ✂ ---------- H1 Denkanstoß: Was ist gesucht? ----------

### H1 – Ist ein Winkel gesucht?

**Frage dich:** Steht das Gesuchte **in der Klammer** – also sin(**?**)?

- **Ja, ein Winkel ist gesucht** → du brauchst die **Umkehrfunktion** sin⁻¹, cos⁻¹ oder tan⁻¹.
   Erst den Quotienten ausrechnen, dann SHIFT sin (bzw. cos, tan).
- **Nein, eine Seite ist gesucht** → **keine** Umkehrfunktion! Du stellst die Gleichung um (siehe H2).

**Kontrolle:** Ein Winkel im rechtwinkligen Dreieck liegt **zwischen 0° und 90°**. Hast du 0,01 oder 0,64 heraus? Dann fehlt die Umkehrfunktion oder der TR steht auf RAD.

> ✂ ---------- H2 Strategie: drei Fälle ----------

### H2 – Umstellen: Wo steht das Gesuchte?

| Fall | Beispiel | So stellst du um |
|---|---|---|
| **Kathete gesucht** (steht **oben** im Bruch) | sin(α) = **a** : c | **mal c**: a = c · sin(α) |
| **Hypotenuse gesucht** (steht **unten** im Bruch) | sin(α) = a : **c** | ① **mal c**: c · sin(α) = a  ② **geteilt durch sin(α)**: c = a : sin(α) |
| **Winkel gesucht** (steht **in der Klammer**) | sin(**α**) = a : c | **Umkehrfunktion**: α = sin⁻¹(a : c) |

**Probe mit einfachen Zahlen:** 0,5 = 4 : x → x muss 8 sein, denn 4 : 8 = 0,5. Also: x = 4 : 0,5 ✓
Das gilt genauso für cos und tan.

> ✂ ---------- H3 Beispiel: Hypotenuse und Winkel ----------

### H3 – Zwei Parallelbeispiele (andere Zahlen!)

```dreieck
winkel_A: 35
winkel_B: 55
seiten: AB="c = ?" AC="b = 4,0 cm" BC="a"
winkel: A="α = 35°"
breite: 220
```

**Beispiel 1 – Hypotenuse gesucht.** b = 4,0 cm ist die **Ankathete** von α → cos.
cos(35°) = 4,0 : c  | · c
c · cos(35°) = 4,0  | : cos(35°)
c = 4,0 : cos(35°) = 4,0 : 0,8192 ≈ **4,9 cm**
Probe: 4,9 > 4,0 ✓ (Hypotenuse ist am längsten)

```dreieck
winkel_A: 30.3
winkel_B: 59.7
seiten: AB="c" AC="b = 6,0 cm" BC="a = 3,5 cm"
winkel: A="α = ?"
breite: 220
```

**Beispiel 2 – Winkel gesucht.** a = 3,5 cm ist **Gegenkathete**, b = 6,0 cm **Ankathete** von α → tan.
tan(α) = 3,5 : 6,0 ≈ 0,5833
α = tan⁻¹(0,5833) ≈ **30,3°**   TR: **SHIFT tan ( 3,5 ÷ 6 ) =**
Probe: zwischen 0° und 90° ✓ · a ist kürzer als b, also α < 45° ✓
