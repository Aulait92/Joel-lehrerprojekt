# M5.6 – Hilfekarten Sinussatz (Std. 5, gelten auch für Std. 6)

## Teil A – Für die Lehrkraft (nicht austeilen)

- **Einsatz:** Std. 5 (AB5, alle Niveaus) und Std. 6 (Stationen). Regel „Erst 3, dann ich“: H1 → H2 → H3, dann Partner:in, dann Lösungsstation, dann Lehrkraft.
- Je Tisch bzw. Station einen Satz auslegen (einmal kopieren, ausschneiden, möglichst laminieren). Die Karten sind niveauübergreifend nutzbar.
- **H1** zielt auf PAAR, **H2** auf UMS (Seite gesucht vs. Winkel gesucht), **H3** ist ein durchgerechnetes Parallelbeispiel mit anderen Zahlen. **Karte W** hilft bei Winkelaufgaben (UMK). **Karte S** ist der Prüf-Check für Std. 6 (FALL, SSW).
- Alle Zahlen sind nachgerechnet: H3 b ≈ 8,6 cm; Karte W β ≈ 42,7°.

## Teil B – Kopiervorlage Hilfekarten

> ✂ ---------- H1 · Denkanstoß ----------

**H1 · Denkanstoß: Welche Paare gibt es?**

Ein **Paar** = eine Seite und der Winkel, der ihr **gegenüberliegt**.
Lege den Finger auf einen Winkel. Fahre quer durch das Dreieck. Die Seite, auf die du triffst, ist sein Partner.
Klein- und Großbuchstabe helfen: Seite **a** liegt gegenüber der Ecke **A** mit dem Winkel **α**.

Frage dich:
1. Welches Paar kenne ich **ganz** (Seite **und** Winkel)?
2. In welchem Paar steckt die **gesuchte** Größe?
3. Fehlt mir dort der Winkel? Dann zuerst: Winkelsumme 180°.

> ✂ ---------- H2 · Strategie ----------

**H2 · Strategie: Ansetzen und Umstellen**

Schreibe die beiden Paare als Gleichung auf. Die **gesuchte Größe** schreibst du **links oben**.

**Seite gesucht** (z. B. b):
  b : sin(β) = a : sin(α)   | · sin(β)
  **b = a · sin(β) : sin(α)**
Merksatz: „gesuchte Seite = bekannte Seite · sin(Winkel **gegenüber der gesuchten Seite**) : sin(Winkel **gegenüber der bekannten Seite**)“

**Winkel gesucht** (z. B. β): Sinus nach oben!
  sin(β) : b = sin(α) : a   | · b
  **sin(β) = b · sin(α) : a**,  dann **β = sin⁻¹( … )**

TR-Check: DEG-Modus? sin(30) = 0,5.

> ✂ ---------- H3 · Parallelbeispiel ----------

**H3 · Parallelbeispiel (andere Zahlen)**

Gegeben: a = 5,0 cm, α = 35°, β = 80°. Gesucht: b.

```dreieck
winkel_A: 35
winkel_B: 80
seiten: AB="c" AC="b = ? ■" BC="a = 5,0 cm ●"
winkel: A="α = 35° ●" B="β = 80° ■" C="γ"
breite: 240
```

1. Vollständiges Paar ●: a = 5,0 cm und α = 35°.
2. Paar mit der Gesuchten ■: b und β = 80°.
3. Ansatz: b : sin(80°) = 5,0 : sin(35°)
4. Umstellen: b = 5,0 · sin(80°) : sin(35°)
5. TR: 5 × sin 80 ÷ sin 35 = 4,9240 : 0,5736 ≈ 8,585
6. Ergebnis: **b ≈ 8,6 cm**
7. Prüfen: γ = 180° − 35° − 80° = 65°. Größter Winkel β = 80° → b ist die längste Seite ✓

> ✂ ---------- Karte W · Winkel gesucht ----------

**Karte W · Winkel gesucht (Parallelbeispiel)**

Gegeben: a = 9,0 cm, α = 70°, b = 6,5 cm. Gesucht: β.

1. Ansatz mit dem Sinus oben: sin(β) : 6,5 = sin(70°) : 9,0
2. Umstellen: sin(β) = 6,5 · sin(70°) : 9,0 = 6,1080 : 9,0 ≈ 0,6787
3. Umkehrfunktion: β = sin⁻¹(0,6787) ≈ **42,7°** (Taste SHIFT/2nd + sin)
4. Prüfen: b < a, also muss β < α sein: 42,7° < 70° ✓

Typische Falle: sin(0,6787) statt sin⁻¹(0,6787) eintippen. Dann kommt etwa 0,01 heraus – kein sinnvoller Winkel.

> ✂ ---------- Karte S · Geht der Sinussatz? (Std. 6) ----------

**Karte S · Geht der Sinussatz überhaupt?**

| Gegeben | Sinussatz? |
|---|---|
| WSW / SWW (eine Seite, zwei Winkel) | **ja** – fehlenden Winkel über 180° |
| SSW (der Winkel liegt einer **gegebenen** Seite gegenüber) | **ja** – aber prüfen: Gibt es eine zweite Lösung 180° − β? |
| SWS (Winkel **zwischen** den Seiten) | **nein** → Kosinussatz (Std. 7) |
| SSS | **nein** → Kosinussatz (Std. 7) |

**SSW-Check:** Du hast β = sin⁻¹( … ) berechnet. Rechne auch β₂ = 180° − β. Ist α + β₂ < 180°? Dann gibt es **zwei** Dreiecke. Die Sachsituation entscheidet, welches passt.
