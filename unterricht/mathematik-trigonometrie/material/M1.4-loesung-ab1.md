## Teil F – Lösung Merkblatt „Sinus, Kosinus und Tangens in rechtwinkligen Dreiecken“

**Merke: Hypotenuse, An- und Gegenkathete** (Dreieck ABC, rechter Winkel bei C, Winkel α bei A markiert)
- c (gegenüber dem rechten Winkel) = **Hypotenuse**
- b (liegt an α) = **Ankathete von α**
- a (liegt α gegenüber) = **Gegenkathete von α**

**Merke: Trigonometrische Verhältnisse**
sin(α) = Gegenkathete von α : Hypotenuse = a : c
cos(α) = Ankathete von α : Hypotenuse = b : c
tan(α) = Gegenkathete von α : Ankathete von α = a : b

**Merksatz (korrigiert):** Haben rechtwinklige Dreiecke die gleichen Innenwinkel, dann **sind die Verhältnisse entsprechender Seiten gleich (sie hängen nur vom Winkel ab)**.
*(Im Tafel-PDF steht handschriftlich „beträgt diese 45°“ – das ist falsch.)*

**Beispiel (korrigiert):** Ein rechtwinkliges Dreieck hat die Winkel α = 60°, β = 30° und **γ = 90°**.
*(Im Tafel-PDF steht „γ = 30°“ – falsch; die Winkelsumme wäre sonst nur 120°.)*

| | von mir ermittelt (gemessen a ≈ 5,1 cm, b ≈ 3,2 cm, c ≈ 6,0 cm) | vom Taschenrechner |
|---|---|---|
| sin(α) | a : c = 5,1 : 6 ≈ 0,85 | sin(60°) ≈ 0,866 ≈ 0,87 |
| cos(α) | b : c = 3,2 : 6 ≈ 0,53 | cos(60°) = 0,5 |
| tan(α) | a : b = 5,1 : 3,2 ≈ 1,59 | tan(60°) ≈ 1,732 ≈ 1,73 |

Die Abweichungen entstehen durch Messungenauigkeit (bei exakt 60° und c = 6,0 cm wäre b = 3,0 cm). Das ist ein guter Gesprächsanlass: „Gemessen ist nie ganz genau – der Taschenrechner kennt den exakten Wert.“
