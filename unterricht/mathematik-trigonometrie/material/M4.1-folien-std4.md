### Folie 4 – 3-2-1-hoch: Wo ist ein rechter Winkel?

Schau auf das Dreieck **S₂ – S₁ – D**.
**a)** Hat es einen rechten Winkel? **b)** Darf man rechnen: tan(α₂) = x : d?

🪶 Zeige auf alle rechten Winkel in der Skizze. ◼◼ Begründe in einem Satz.

*Moderation:* 60 Sek., dann hoch. Auflösung: Der rechte Winkel liegt an der Wand – aber im Dreieck S₂S₁D gibt es keinen. tan(α₂) = x : d ist falsch (Fehlerbild RW), denn die Ankathete zu α₂ ist d + e.

### Folie 5 – Think-Pair (2′ + 3′)

### Folie 6 – Musterbeispiel 1: Grundstück (Lehrkraft rechnet laut)

Ein dreieckiges Grundstück (angenommen): b = 45,0 m, α = 52°, β = 68°. **Wie lang ist die Grenze a?**

```dreieck
winkel_A: 52
winkel_B: 68
seiten: AC="b = 45,0 m" BC="a = ?" AB="c"
winkel: A="α = 52°" B="β = 68°"
breite: 260
```

**Schrittweise aufdecken:**
1. Höhe h von C auf c. In Teildreieck ① ist **b** die Hypotenuse.
2. h = b · sin(α) = 45,0 · sin(52°) ≈ **35,46 m** (im TR lassen)
3. Teildreieck ②: h = a · sin(β) ⇒ a = h : sin(68°) = 35,46 : 0,9272 ≈ **38,2 m**
4. Prüfen: γ = 60°. a liegt α = 52° gegenüber, dem **kleinsten** Winkel → a ist die kürzeste Seite: 38,2 m < 45,0 m ✓

*Moderation:* Laut denken. Bei Schritt 4 kurz „fast falsch“ denken („a liegt doch bei β …?“) und korrigieren: Gegenüber heißt nicht „daneben“ (AG). Optional für Schnelle: c = 45,0 · cos 52° + h : tan 68° ≈ 27,70 + 14,33 ≈ 42,0 m.

### Folie 7 – Musterbeispiel 2: Sonnensegel (Klasse diktiert)

Ein dreieckiges Sonnensegel: c = 12,0 m, α = 35°, β = 75°. **Wie lang ist die Kante a?**

```dreieck
winkel_A: 35
winkel_B: 75
seiten: AB="c = 12,0 m" BC="a = ?" AC="b"
winkel: A="α = 35°" B="β = 75°"
breite: 240
```

**Frage an die Klasse:** Die Höhe von C auf c hilft hier nicht. Warum? Welche Höhe dann?

**Schrittweise aufdecken:**
1. Höhe h von **B** auf b. Dann ist **c** die Hypotenuse von Teildreieck ①.
2. h = c · sin(α) = 12,0 · sin(35°) ≈ **6,88 m**
3. γ = 180° − 35° − 75° = 70°. Teildreieck ②: h = a · sin(γ) ⇒ a = 6,883 : sin(70°) ≈ **7,3 m**
4. Prüfen: a liegt dem kleinsten Winkel gegenüber → kürzeste Seite ✓ (b ≈ 12,3 m, c = 12,0 m)

*Moderation:* Die Klasse diktiert, Lehrkraft schreibt. MWB-Zwischenfrage nach Schritt 1: „Zeige die Hypotenuse von Teildreieck ①.“

### Folie 8 – Zerlegen in 4 Schritten (ins Heft)

1. **Skizze + Höhe:** Höhe so einzeichnen, dass die **bekannte Seite Hypotenuse** wird. Rechte Winkel markieren, Teildreiecke ① ② nummerieren.
2. **Höhe berechnen** (Teildreieck ①): h = bekannte Seite · sin(Winkel)
3. **Zweites Teildreieck:** fehlenden Winkel (Winkelsumme), h = gesuchte Seite · sin(Winkel) ⇒ umstellen
4. **Prüfen:** größte Seite gegenüber größtem Winkel? Einheit, Rundung, Antwortsatz

*Moderation:* 🪶 bekommt das Schema als Kärtchen (M4.6, H2). Alle anderen schreiben ab (2′).

### Folie 10 – Rückkopplung: Stimmt unsere Messung?

| Weg | Daten | Dachhöhe |

**Gleiches Ergebnis?** Woher kommen die 2 cm?

*Moderation:* Ein ◼◼-Tandem rechnet vor (Lot S₁L ≈ 4,24 m → S₁D ≈ 19,0 m → x ≈ 11,70 m), alle prüfen am MWB. Auflösung: α₂ wurde auf 0,1° gerundet (exakt 25,116°). Messgenauigkeit ±0,4 m – die 2 cm sind bedeutungslos. Danach 1–2 Trupps mit eigenen Daten vergleichen: „Mit euren eigenen Daten weicht die Zerlegung oft um 1–2 m ab. Der Winkel an der Dachkante ist klein, deshalb verschiebt 1° Ablesefehler die Höhe um mehr als 1 m (M3.5, Empfindlichkeitstabelle). Das ist kein Rechenfehler, sondern eine Büro-Erkenntnis: d groß wählen.“
