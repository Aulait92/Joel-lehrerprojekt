# M6.5 – Laufkarte „Baustellen-Rundgang“ mit Freigabe-Code

## Teil A – Für die Lehrkraft (nicht austeilen)

- **Stunde 6**, eine Laufkarte pro Person. Alle schreiben selbst mit, auch in der Gruppe.
- **Codewort: TURM** (Station 1 → T, 2 → U, 3 → R, 4 → M). Jede Niveau-Karte einer Station führt auf **denselben** Buchstaben. Deshalb kann eine Gruppe die Niveaus mischen, und es entsteht kein Vergleich zwischen den Niveaus.
- Die Gruppen starten an verschiedenen Stationen. Die Buchstaben werden trotzdem in der Reihenfolge der **Stationsnummern** eingetragen.
- Distraktoren zeigen typische Fehler: K, S, E, O (PAAR bei 🪶), A und P (Zwischenergebnis statt Endergebnis), B (Sparren statt Firsthöhe), L (AT statt BT), H (Lage von F statt Brückenlänge), N (AUG), X (unrealistische SSW-Lösung).
- **Büro-Rekord:** Jede Gruppe mit vollständigem Code meldet sich am Ende. Der Balken an der Tafel wächst um 1 pro gelöster Station (Zählung über die Klasse, keine Gruppenrangliste).

### Laufkarte: Baustellen-Rundgang

**Auftrag 6/8 · Vermessungsbüro Spree-Vermessung:** Vier Baustellen, vier Messaufträge. Jede gelöste Station liefert einen Buchstaben für die Freigabe.

**Regeln**
1. **Gong = Wechsel.** Alle 8 Minuten geht ihr eine Station weiter, **im Uhrzeigersinn** (1 → 2 → 3 → 4 → 1).
2. Ihr wählt an jeder Station eine Karte: 🪶, ◼ oder ◼◼. Wechseln ist erlaubt.
3. **Alle** schreiben mit. Eine Person rechnet, eine prüft, eine liest vor. Die Rollen wechseln an jeder Station.
4. Hilfe: Hilfekarten (H1 → H2 → H3, Karte S) → Gruppe → Lösungsstation → Lehrkraft.
5. Nach Station 2: **1 Minute Stopp** für den Zwischenstand.

**Vorgehen an jeder Station:** (1) Skizze ansehen, Gegebenes markieren · (2) Paar finden · (3) ansetzen und umstellen · (4) prüfen (Winkelsumme, längste Seite ↔ größter Winkel, Sachsituation)
