## Teil C – Lösung Merkblatt (nicht austeilen, als Folie nutzbar)

**Merke 1:** Tabelle ist vorgegeben. In der Skizze c und γ in derselben Farbe.

**Merke 2:** c² = **a² + b²**

| γ | cos(γ) ist … | Korrektur | c ist … |
|---|---|---|---|
| kleiner als 90° | **positiv** | wird **abgezogen** | **kürzer** |
| genau 90° | **0** | fällt **weg** | genau so lang |
| größer als 90° | **negativ** | wird **addiert** | **länger** |

**Merke 3:** a² = b² + c² − 2bc · cos(**α**) · b² = a² + c² − 2ac · cos(**β**) · c² = **a²** + **b²** − 2 · **a** · **b** · cos(γ). Der Winkel liegt der gesuchten Seite **gegenüber** (und wird von den beiden anderen Seiten eingeschlossen).

**Merke 4:** ① cos(α) = **x / b**, x = b · **cos(α)** · ② h² = **b²** − x² · ③ a² = h² + (**c − x**)² · ④ … = b² + c² − 2 · c · **x** · ⑤ a² = b² + c² − 2 · **b** · **c** · cos(α)

**Merke 5:** cos(γ) = **(a² + b² − c²) / (2ab)** · cos(α) = **(b² + c² − a²) / (2bc)** · cos(β) = **(a² + c² − b²) / (2ac)**

**Merke 6:** cos(90°) = **0** · 2ab · cos(γ) = **0** · c² = **a² + b²**

**Beispiel:** c² = 3² + 5² − 2 · 3 · 5 · cos(120°) = 9 + 25 − 30 · (−0,5) = 34 + 15 = **49** · c = **7 cm**. Gemessen in einer sauberen Zeichnung: etwa 7,0 cm.
